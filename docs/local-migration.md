# Rememo の端末内保存への段階移行

## 現在の実装段階

ログイン不要の端末内モードを追加した段階です。既存クラウド・ログイン機能を残しています。DBスキーマ変更、クラウドデータの削除、実利用者の移行、デプロイ・公開は行っていません。利用者が移行を照合してから、別の変更でログイン機能を廃止します。

既存の `study_units` は科目・教材の名前、単元、ページ、メモ、学習日時、作成日時、復習段階と次回日時を保持しています。`review_logs` は学習記録ID、予定・実施日時、理解度、前後の復習段階を保持しています。クラウドのアクセスは引き続き既存Supabaseクライアントとユーザー別RLSを使用します。

## 移行手順

1. 同じアプリURLで既存クラウドにログインします。他端末の編集を一時停止します。
2. 設定の「既存クラウドデータをJSONエクスポート」を選び、全件取得後に作成されたJSONをiCloud Driveなどへ保存します。500件ずつ全件取得し、2回の読み取りが一致しない場合は書き出しません。読み取りのみで、クラウドは変更しません。
3. ファイルが保存できたことを確認し、端末内モードに切り替えます。設定のファイル選択からそのJSONを読み込みます。
4. 作成日時・科目・教材・学習記録・復習予定・履歴の件数を確認し、復元方法を選択して確認します。置換する場合は現在の端末データを先にバックアップしてください。
5. ホーム・学習記録・カレンダーで日時・メモ・履歴を照合します。再読み込み、ブラウザの終了・再起動後にも残ることを確認します。
6. 設定で「移行確認を記録する」を実行します。この操作もログイン機能を消しません。利用者が移行完了を伝えた後にログインの最終廃止を行います。

クラウドの記録IDと履歴ID、全ての学習・予定・実施日時、復習段階を維持します。科目と教材の名前から安定したIDを付与します。空の科目・教材名のみ「科目未設定」「教材未設定」と表示します。同じ科目に同名の教材は一つにまとめます。文字列以外のクラウド情報（ユーザーIDやセッション）はバックアップに出力しません。復習間隔の唯一の実装 `src/lib/srs.ts` は変更していません。

## バックアップと手動同期

JSON形式 `format: rememo`, `version: 1`。科目、教材、学習記録（次回予定を含む）、復習履歴（評価を含む）、メモ、前回選択の設定、作成日時を収録します。ダウンロード名にも日時を含めます。認証情報は含みません。

Safariのダウンロードと標準ファイル選択を使用します。iCloudへの保存先は利用者が選びます。アプリはダウンロード後に実際にiCloudへ保存されたかを検知できません。最終バックアップ日時は端末のJSON生成・ダウンロード開始時のみ更新し、別端末の日時を復元時に流用しません。未作成または7日経過でアプリ内に案内を表示します。

統合は同一IDの完全一致を重複追加せず、異なるIDのデータを追加します。同一IDの内容変更や同じ単元の復習履歴の相違は自動解決しません。衝突箇所を表示して書き込みを中止します。片側だけを正しいと判断すると復習段階や履歴を失うためです。両方のバックアップを保持し、必要な内容を照合してから復元してください。削除の伝播はせず、端末側の前回選択設定を維持します。空の端末ではファイルの設定を読み込みます。置換ではバックアップの設定も読み込みます。

形式・ID重複・参照先・日時・復習段階を検証した後、全データを単一のIndexedDBトランザクションで保存します。失敗時は全体を中止します。確認後に別タブで変更された場合は復元を中止し、再選択を求めます。登録・編集・復習も読み取りと書き込みを同一トランザクションにし、復習履歴と段階を一緒に保存します。

## 保持と制限

Mac・iPhone・iPad、ブラウザ、サイトURL（オリジン）ごとに別データです。プレビューURLから本番URLへの移動でもJSONを使って移してください。IndexedDBとモード選択用localStorageが使用可能である必要があります。ブラウザのデータ消去・プライベートブラウズ・容量不足・OSによる削除に対する完全な永続保証はありません。バックアップを継続してください。アプリ本体の完全オフライン起動を保証するPWA対応は今回の対象外です。

端末内モードで学習データの読み書きや認証セッション取得は行いません。既存クラウドへの明示的な切替時はページ全体を読み直してキャッシュを分離します。既存クラウドモードの入力は移行前の互換性のため従来どおりです。端末内モードでは科目・教材を選択し、固定IDで関連付けます。参照されている科目・教材の削除や教材の別科目への移動は禁止します。

## 検証

既存のSRS・ルーティングテストに加え、JSONの往復、整合性、統合競合、全件ページング、アカウント変更、IndexedDBの中止・同時更新・古い確認の拒否・名前変更・参照保護・バックアップ日時をテストします。

新規のテスト用Chromium領域でiPhone幅の入力・インライン追加・リロード後の保持・前回選択・復習・JSON書き出し・重複なしの統合・別端末領域への復元を確認します。実利用者のクラウドデータやiCloudへの実保存を検証したものではありません。
